It does not mean every byte string, URL or scheduler interleaving has been enumerated. A newly discovered violation still blocks progression. An added requirement must name its normative assertion, missing family or invariant and finite reproduction; “broader”, “full attack coverage” or “entire long corpus” alone is not an executable acceptance condition.
