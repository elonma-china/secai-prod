Phân tích

Log4Shell (CVE-2021-44228) khai thác tính năng JNDI lookup trong Log4j 2. Khi một chuỗi ${jndi:ldap://…} được ghi log, Log4j sẽ truy vấn máy chủ LDAP do kẻ tấn công kiểm soát và tải về class Java độc hại.

Điều kiện

  • Log4j 2.0-beta9 → 2.14.1
  • Đầu vào người dùng đi vào log message

Tham khảo: NVD · CVE-2021-44228
