# OCR model selection: all three allowed candidates assessed

Status 2026-10-04: **not production accepted** after all three allowed checkpoints were loaded. PaddleOCR-VL-1.6 passed numeric raw OCR thresholds on a deterministic 62-image synthetic corpus but failed Arabic logical reading order. Qwen3.5-2B failed separate Arabic calibration. Qwen3-VL-2B-Instruct improved Arabic order and met numeric raw OCR thresholds on the frozen 62×3 **agent-authored synthetic** corpus, with a visible IP error on `a62` in every round. Its aggregate IP F1 of 0.975 per round still exceeds the 0.95 threshold. No fourth model will be tried, and no production OCR model is selected. Qualified native/public ground truth, corrected OCR, full translation jobs, real document/photo evidence, and independent stage gates remain open; import work is stopped at its review gate. This report does not use vendor scores as local evidence.
