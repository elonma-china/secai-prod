No Seed-X weights were downloaded or loaded, and no serving process was changed. This is a conditional translation-model comparator if the incumbent DuyTa remains unsuitable after paired prompt diagnostics; it is not a fourth OCR/LID/QE helper or a production replacement.

The pinned candidate is `ByteDance-Seed/Seed-X-PPO-7B-AWQ-Int4` revision `3c253e97b088cefc32227c49bdd5a13fa4fa197c`. Its single weight file is 4,668,700,560 bytes (4.348 GiB), SHA-256 `97f322401c87f63f24fccda2d0e29ea0d8d29b7a774a77ab8433486498fe9c5e`. These are repository metadata, not a successful runtime load.

Remote base Python has vLLM 0.25.1 and compressed-tensors 0.17.0. Installed vLLM source contains W4A16, group-size, Marlin and packed-quantization paths; [vLLM 0.25.1 lists MistralForCausalLM](https://docs.vllm.ai/en/v0.25.1/models/supported_models/). This supports trying the candidate later, but does not prove this exact checkpoint runs on the installed backend.

At a tentative per-instance `--gpu-memory-utilization 0.09`, [vLLM's GPU-memory fraction](https://docs.vllm.ai/en/v0.25.1/configuration/engine_args/) corresponds to about 7,373 MiB of the full A100, leaving about 2,637 MiB of the **observed** 10,010 MiB free if the whole budget is allocated. A 2,048-token sequence with the published 32 layers/8 KV heads/128 head dimension/BF16 implies about 256 MiB of KV tensors. The 4.348 GiB weight file plus this KV estimate leaves roughly 2.60 GiB inside the tentative vLLM budget for engine buffers, activations, fragmentation and untallied allocations. The actual peak, model-loader compatibility, and available memory after OCR are unknown; no fit claim can be made without a separately bounded trial after the shared GPU is released. Eager execution, one sequence, 2,048 maximum model length and 2,048 batched-token ceiling would be conservative initial controls. An explicit KV-byte reservation should not be combined with the utilization budget without measuring its interaction.

The currently running DuyTa/embedding/rerank processes are preserved. No conditional candidate trial starts until the DuyTa prompt ablation is complete, the OCR owner has released its GPU process, and fresh headroom is verified. The user authorized comparison models only if DuyTa fails; this note does not change any acceptance threshold or model-selection decision.
