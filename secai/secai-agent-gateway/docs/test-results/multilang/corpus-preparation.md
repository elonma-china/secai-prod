# Reference corpus preparation (metadata only)

Checked 2026-10-03/04. No source sentence or reference has been downloaded, fabricated or scored. Dataset access and qualified review are still required; assessment quality status is **NOT RUN**.

The [FLORES+ dataset card](https://huggingface.co/datasets/openlanguagedata/flores_plus) identifies CC BY-SA 4.0, version 4.6, 997 aligned dev sentences and 1,012 aligned devtest sentences per language, with an external blind test absent from that repository. The Hugging Face metadata API currently reports revision e707e62e762a9e2faca3933aa315f4665cc3cd8f and gated automatic access. A dataset user must accept the displayed conditions before fetching files. We have only read metadata; no token or protected content is copied into this worktree. [Facebook's older FLORES dataset](https://huggingface.co/datasets/facebook/flores) is likewise gated and no longer updated.

The [source registry](../../../evals/multilang/source-registry.json) pins the candidate revision and maps ten task codes to FLORES+ languoids. Its ar mapping is Modern Standard Arabic arb/Arab, zh-Hans is Standard Beijing Mandarin cmn/Hans, and the available spa/Latn entry is labelled *Latin American Spanish*. That variant requires explicit corpus review before claiming general Spanish coverage. The dataset card's [language table](https://huggingface.co/datasets/openlanguagedata/flores_plus) supports the mappings.

When an authorized tester provides the pinned data, derive both directions from the same aligned sentence ID and keep every article/source-document group in one split across all languages and reversals. Put the source's stable aligned sentence identifier in `aligned_item_id` and the wider document key in `source_group`; do not invent IDs separately per language. Use dev only for DEV. Put devtest in tester custody as sealed TEST; do not expose its source/reference/output to candidate developers or use it for prompt selection. Preserve dataset ID, document URL/group, variant, revision, license and the exact reference. Run validate_corpus.py with all 18 directions and at least 30 **distinct source groups** per direction before a live schedule. A manifest-supplied ID cannot itself prove cross-language alignment; an independent tester must verify it against pinned source records. This general-news corpus alone does not cover all security/domain strata, CVE/IP literals, register or short mixed-script cases, so separately sourced/reviewed technical references remain required. Do not treat model output, self-translation, BLEU/chrF++ or an uncalibrated judge as gold.

The original [FLORES-200 benchmark README](https://github.com/facebookresearch/flores/blob/main/flores200/README.md) lists arb_Arab for MSA and recommends chrF++ (word order 2) as a primary metric. Diagnostic scores in this harness use sacrebleu 2.5.1 with explicit signatures; the ≥70% gate still depends on independent rubric adjudication.
