## Frozen metric definition

Normalize ground truth and model output by Unicode NFC, then CRLF→LF only. Preserve case, diacritics, punctuation, spaces and remaining newlines; no trim, collapse, token removal or output repair in scorer. Reading order annotated before run. Unicode code-point Levenshtein substitutions S, deletions D, insertions I; `CER=(S+D+I)/N`, `accuracy=100*max(0,1-CER)`. Micro accuracy uses sum distances/sum N, macro averages per-image clipped accuracy. Report unclipped CER too. Corrected micro/macro must be >= corresponding raw per round; do not hide regression by aggregate across rounds. Failure/timeout for nonempty image contributes empty output (CER=1) and functional FAIL; no dropping hard samples.

Technical tokens: ground-truth occurrence offsets and class labels annotated before OCR. Align occurrences to ground truth text/order; exact characters required, duplicate/spurious occurrences are FP, missed/wrong occurrences FN (wrong guessed replacement also FP). `precision=TP/(TP+FP)`, `recall=TP/(TP+FN)`, `F1=2TP/(2TP+FP+FN)`; report denominators and mark absent class N/A, not 100%. CVE and IP/CIDR each need >=30 ground-truth occurrences in corpus across >=8 images to prevent vacuous F1. Software/version/path/command annotations include exact spans, not only regular expressions. Distinguish OCR correctness relative to image (>=95% F1 target for CVE/IP) from downstream preservation relative to raw/corrected input (100%); preservation cannot repair an OCR misread.

Blank images excluded from CER since N=0; all must produce empty OCR/NO_TEXT_DETECTED, hallucination count zero. Negative cases never inflate quality averages. `needs_review` is uncertainty signal, not permission to exclude an image or mark it successful when metrics fail.

## Corpus, repetitions and evidence

30 nonblank images minimum: 8 clear VI, 4 clear EN, 8 technical screenshots with CVE/IP/URL/code, 6 phone perspective/skew, 4 blur/low contrast/rotation. Declare language+technical subset membership separately (may overlap), each VI/EN/technical subset >=4 images. Include accented VI plus technical material in overlapping samples. Native source document or independent human transcription establishes ground truth; no AI-generated image/text as authoritative ground truth. Additional blank, corrupt, bomb, spoof, PDF/SVG, metadata and injection negatives mandatory outside 30 positives.

Manifest freezes sample IDs, SHA256 bytes, ground-truth paths, stratum/subsets, expected language/error, protected-span annotations and translation semantic propositions before benchmark. Three different fixed shuffle seeds; same 30 images repeated = 90 runs, not 90 independent samples. Disable result cache; warmup/cold load separately. Record model revision, quantization, all preprocessing/correction prompts/settings, hardware allocation and service revisions per run. Benchmark alternatives and chosen model using identical score policy. Retain raw and corrected outputs separately, safe synthetic-only artifacts.
