Chưa có phiên kiểm thử nào — tính năng "Giải thích quy trình tạo PoC" chưa code (xem readme.md thư mục cha).

Khi tính năng được code xong, kết quả mỗi phiên test lưu tại đây theo tên `results/YYYY-MM-DD-NN.txt`, không ghi đè phiên cũ — cùng quy ước với module-map/poc/results/.

Nếu đã chạy "dry-run baseline" (02-test-giao-dien-tung-buoc.txt mục 0) trước khi có code, lưu kết quả dry-run tại đây với tiền tố `baseline-YYYY-MM-DD.txt`.
