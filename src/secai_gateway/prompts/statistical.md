- "report_detail": phân tích chuyên sâu (lỗ hổng, điểm yếu, mối đe doạ, khuyến nghị), chuỗi Markdown có cấu trúc rõ ràng (heading, danh sách, in đậm); kết thúc bằng ký tự "\n".
